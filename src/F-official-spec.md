# F. 官方规格速查：本书用到的每个数字

> 数据来源：乐鑫《ESP32-C3 系列芯片技术规格书》v2.0（以下简称"规格书"）
> 与《ESP32-C3 技术参考手册》。下表只收本书正文出现过的数字，
> 每行都标了规格书里的章节或表号，方便你直接核对原文。
>
> 与本书第 1 章的区别：第 1 章讲的是**这块板**（FoloToy AI Passport 的板级设计），
> 本章讲的是**芯片本身**。板子是在芯片规格之内做的减法。

## F.1 CPU 与存储

| 项目 | 官方数值 | 出处 |
| --- | --- | --- |
| CPU | 32 位 RISC-V 单核，主频高达 160 MHz | 规格书 §3 / §4.1.1.1 |
| 性能参考 | 407.22 CoreMark @160 MHz（2.55 CoreMark/MHz） | 规格书 §3 |
| ROM | 384 KB | 规格书 §3 / §4.1.2.1 |
| SRAM | **400 KB（其中 16 KB 专用于 cache）** | 规格书 §3 / §4.1.2.1 |
| RTC SRAM | **8 KB**（深睡时仍保持，RTC_DATA_ATTR 变量的总量上限） | 规格书 §3 / §4.1.2.1 |
| eFuse | 4096 bit，其中用户可用 1792 bit | 规格书 §3 / §5 |
| 内置 flash | 本型号 4 MB（QFN32），默认最高时钟 80 MHz | 规格书 §1.2 / §2.6 |
| 外接 flash 映射 | CPU 最大可寻址 16 MB | 规格书 §4.1.2.2 |
| cache | 16 KB，块大小 32 字节 | 规格书 §4.1.2.3 |

**为什么"400 KB"和第 1 章的"可用堆约 230 KB"对不上**：400 KB 是芯片总量。
扣掉 16 KB cache、IDF 的系统占用、任务栈、静态分配（LVGL 池 24 KB、
绘制缓冲 19.2 KB 等），留给 `malloc` 的就只剩 230 KB 左右——
而且这是碎片化之后的"最大连续块 < 8 KB"（第 11 章）。

## F.2 低功耗（规格书 §5.6）

| 模式 | 官方典型值 | 备注 |
| --- | --- | --- |
| Deep-sleep | **5 µA** | RTC 定时器 + RTC 存储器保持；这就是第 8/31 章深睡的官方锚点 |
| Light-sleep | **130 µA** | VDD_SPI 与 Wi-Fi 掉电，所有 GPIO 高阻 |
| 关闭（CHIP_EN 拉低） | 1 µA | |
| Modem-sleep | 160 MHz CPU 工作 23 mA；空闲 16 mA | Wi-Fi 时钟门控，表 5-8 |
| Wi-Fi TX 峰值 | 802.11b 1 Mbps @21 dBm：**335 mA** | 表 5-7，100% 占空比 |
| Wi-Fi RX | 84~87 mA | 表 5-7 |

**能待机多久**（520 mAh 电芯，第 8 章）：

- 深睡理论值：520 mAh ÷ 5 µA ≈ **10 万小时 ≈ 11 年**（只有 RTC 定时器和 8 KB RTC 内存活着）
- Wi-Fi 连续发射：520 mAh ÷ 335 mA ≈ **1.5 小时**

这就是第 8 章为什么把"熄屏 + 深睡"当核心功能——两种状态差 6 万倍。
当然实测还要算上稳压器静态电流和按键电路漏电流，所以第 8 章的实测值比理论高。

## F.3 ADC（规格书 §5.5 / §4.2.2.1）

| 项目 | 官方数值 | 出处 |
| --- | --- | --- |
| 结构 | 2 个 12 位 SAR ADC，共 6 个通道：**ADC1 5 通道 + ADC2 1 通道** | §4.2.2.1 |
| 通道分布 | ADC1_CH0~CH4 = **GPIO0~GPIO4**；ADC2_CH0 = **GPIO5** | 表 2-6 / 表 2-7 |
| 采样速度 | 最高 **100 kSPS** | 表 5-5 |
| 线性度 | DNL ±7 LSB，INL ±12 LSB（输入端接 100 nF 电容、直流输入、关 Wi-Fi） | 表 5-5 |
| 衰减档 | ATTEN0：0~750 mV（±10 mV）；ATTEN1：0~1050（±10）；ATTEN2：0~1300（±10）；**ATTEN3：0~2500 mV（±35 mV）** | 表 5-6 |

**三个官方口径的量程，见第 6.6 节坑 2 的展开**：
规格书表 5-6 说 ATTEN3 有效测量范围 **0~2500 mV**；
IDF v5.5.3 文档说 `ADC_ATTEN_DB_12` "仅支持低于 **2800 mV** 的输入电压"；
而 BSP 源码注释写"0~3100 mV"——**与两个官方来源都不符**，不要当真。

**ADC2 的特殊性**：本板三个按键全在 ADC1（GPIO0）。你要加模拟传感器的话，
ADC2 只剩 GPIO5 一根，而且 **Wi-Fi 工作期间 ADC2 不可用**（驱动层直接报错）——
这是 ESP32 家族的通病，本板又是"Wi-Fi 常开"的使用方式，所以
**模拟量请优先规划在 ADC1 的 GPIO1~GPIO4**（GPIO0 已被按键占用）。

## F.4 管脚与电流（规格书 §2 / §5.4）

| 项目 | 官方数值 | 出处 |
| --- | --- | --- |
| GPIO 总数 | 22 个（flash 型号 16 个） | §3 / §4.1.3.1 |
| Strapping 管脚 | **GPIO2、GPIO8、GPIO9** 三个（不是只有 GPIO9） | §3 / 表 2-7 优先级 3 |
| 启动模式 | SPI Boot：GPIO9=1（GPIO2=1）；Joint Download Boot：GPIO9=0、GPIO8=1 | 表 3-3 |
| ROM 日志控制 | GPIO8 电平 + eFuse 共同决定 UART0 ROM 日志开/关 | 表 3-4 |
| USB 串口/JTAG | GPIO18（D-）/ GPIO19（D+），USB 2.0 **全速 12 Mbit/s**（不是高速 480 Mbit/s） | §4.2.1.5 |
| UART0 | GPIO20 = U0RXD，GPIO21 = U0TXD | 表 2-7 |
| JTAG 接口 | GPIO4=MTMS、GPIO5=MTDI、GPIO6=MTCK、GPIO7=MTDO（本板用内置 USB-JTAG，这四根脚是空闲的） | 表 2-7 / §2.3.4 |
| VDD_SPI | GPIO11，flash 供电；仅当 flash 改外部供电时才可用作 GPIO | §2.3.3 |
| SPI0/1 固定管脚 | GPIO12~GPIO17（与内置 flash 通讯，**禁止挪用**） | 表 2-7 |
| SPI2（FSPI）IO MUX | GPIO2=FSPIQ、GPIO4=FSPIHD、GPIO5=FSPIWP、GPIO6=FSPICLK、GPIO7=FSPID、GPIO10=FSPICS0 | 表 2-7 |
| **驱动电流** | GPIO2、GPIO3、MTMS、MTDI：**10 mA**；GPIO18/19：**40 mA**；其余：**20 mA** | §2.2 注 4 |
| 内部上/下拉 | 约 45 kΩ | 表 5-4 |
| 上电毛刺 | MTCK、MTDO、GPIO10、U0RXD 上电瞬间有 **5 ns 低电平毛刺** | 表 2-2 |

**上电毛刺为什么重要**：GPIO10 是 FSPI 的片选位（FSPICS0）。如果你把 GPIO10 用作
外设片选或复位线，上电瞬间那 5 ns 低毛刺可能让外设"看见"一次假选中。
规格书直接给了这个数字，说明乐鑫自己认为值得写——接敏感外设时记住它。

## F.5 外设速率上限（规格书 §4.2.1）

| 外设 | 数量 | 上限 | 出处 |
| --- | --- | --- | --- |
| SPI | 3 个（SPI0/1 接 flash，SPI2 通用） | SPI0/1 STR 120 MHz；**SPI2 通用主模式 80 MHz** | §4.2.1.2 |
| UART | 2 个 | 5 Mbps | §4.2.1.1 |
| I2C | 1 个 | 标准 100 Kbit/s、快速 400 Kbit/s、**最高 800 Kbit/s**（受 SCL/SDA 上拉限制） | §4.2.1.3 |
| I2S | 1 个 | 8/16/24/32 位，BCK 10 kHz~40 MHz | §4.2.1.4 |
| LED PWM | 6 通道 | 最高 14 位分辨率 | §4.2.1.7 |
| GDMA | 通用 DMA | **3 个发送 + 3 个接收通道**，SPI2/UHCI0/I2S/AES/SHA/ADC 共用 | §4.1.1.2 |
| TWAI（CAN） | 1 个 | 1 Kbit/s~1 Mbit/s | §4.2.1.6 |
| RMT | — | 2 发送 + 2 接收通道 | §4.2.1.8 |
| 定时器 | 2 个 54 位通用 + 3 个数字看门狗 + 1 个模拟看门狗 + 52 位系统定时器 | — | §3 |

**两个和本书直接相关的上限**：

- **屏幕为什么只能 80 MHz**：屏幕走的是 SPI2。规格书说 SPI2 主模式上限
  就是 80 MHz——第 1.2 节那句"屏幕 80 MHz"已经是芯片跑满的速度，
  没有再往上调的余地。
- **GDMA 只有 3+3 个通道**：第 12.4 节说"屏幕 SPI 和音频 I2S 竞争 DMA"，
  现在有了精确数字——整颗芯片所有用到 DMA 的外设（SPI2、I2S、ADC、AES、SHA…）
  共享 3 发 + 3 收。DMA 通道在这颗芯片上是稀缺资源，别乱占。
